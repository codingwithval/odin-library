# Odin Library

A small library project from The Odin Project's JavaScript course. The goal is to build a browser app for keeping track of books.

## Project Goals

- Add books and display them in a library.
- Track whether each book has been read.
- Practice using JavaScript objects, arrays, and DOM manipulation.

## Built With

- HTML
- CSS
- JavaScript

## Run It

Open `index.html` in a web browser.
